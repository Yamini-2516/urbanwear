🛍️ UrbanWear — Premium E-Commerce Website

A modern, stylish E-commerce Clothing Website built using HTML, CSS, JavaScript, and Flask (Python).
This project provides a complete shopping experience including product browsing, cart, wishlist, authentication, and responsive UI.

🚀 Features
🏠 Beautiful Home Page (Hero + Categories + Products)
🛒 Add to Cart functionality
❤️ Wishlist system
🔍 Search & Filter products
📦 Product Detail Page
👤 Login / Signup system
📱 Fully Responsive Design
🎨 Modern UI (Zara / H&M style)
⚡ Fast & lightweight

⚙️ Installation & Setup
1. Clone Project
git clone https://github.com/your-username/urbanwear.git
cd urbanwear
2. Create Virtual Environment
python -m venv venv
3. Activate Virtual Environment
.\venv\Scripts\Activate.ps1
4. Install Dependencies
pip install flask flask-sqlalchemy
5. Run Project
python app.py
🌐 Run in Browser

Open:

http://127.0.0.1:5000
